# 🍕 Pizzelle

Pizzelle es una aplicación web frontend para una pizzería, desarrollada con React y Vite.

El proyecto simula una experiencia completa de compra online, permitiendo al usuario explorar el menú, buscar productos, administrar un carrito y realizar un proceso de pago simulado.

## 📸 Vista del proyecto

### Inicio

Página principal con presentación de la marca, menú y acceso rápido a los productos.

### Catálogo

Los usuarios pueden visualizar las diferentes pizzas disponibles y agregarlas al carrito.

### Carrito

Permite:

- Agregar productos.
- Aumentar cantidades.
- Disminuir cantidades.
- Eliminar productos.
- Calcular el total automáticamente.

### Pago

Incluye un flujo de pago simulado con diferentes métodos:

- 💳 Tarjeta
- 📱 Nequi
- 💵 Efectivo

> Los pagos son simulados y no representan transacciones reales.
